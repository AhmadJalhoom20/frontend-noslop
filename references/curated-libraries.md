# Curated Frontend Libraries (Opinionated & Proven)

Curated from elite design-engineers (including Emil Kowalski's standards). Avoid heavy, unstyled, or unmaintained npm packages.

---

### UI Primitives & Accessibility
* **Radix UI Primitives** (`@radix-ui/*`) / **Base UI** (`@base-ui-components/react`)
  * Headless, accessible, keyboard-first, zero runtime CSS overhead.

### Notifications & Toasts
* **Sonner** (`sonner`)
  * Beautiful stacked toasts, customizable gestures, and fluid spring animations.

### Drawers & Mobile Gestures
* **Vaul** (`vaul`)
  * Smooth, physics-based drag-to-dismiss drawer component for React.

### Command Menus & Search
* **CMDK** (`cmdk`)
  * Fast, unstyled command palette with fuzzy filtering and keyboard navigation.

### Animations & Micro-Interactions
* **Motion** (`framer-motion`)
  * Production-ready declarative animations, layout morphing, and gestures.

### Virtualization (Large Lists & Grids)
* **Virtuoso** (`react-virtuoso`)
  * High-performance, zero-config virtual lists with dynamic heights.

### Tooltips & Floating Elements
* **Floating UI** (`@floating-ui/react`)
  * Anchor positioning, collision detection, and optimal viewport placement.
